# cto-security

The **executive** security toolkit for a CTO (or VP Eng). Focuses on building
security into technology **at scale**: **secure-by-design programs** (paved roads,
guardrails, developer enablement) and **technology-risk assessment** for strategic
decisions (new tech adoption, build-vs-buy, vendor and M&A due diligence) — balancing
security with engineering velocity.

Thin orchestrator: it **auto-installs** `threat-modeling`, `security-diagramming`,
and `security-reporting`, and adds a CTO-advisor persona + strategy skills.

## Install

```
/plugin install cto-security@awesome-claude-security
```

## Command

| Command | What it runs |
| --- | --- |
| `/cto-security:tech-review` | Tech-risk assessment + secure-by-design path for a decision. |

## Skills

| Skill | When it fires |
| --- | --- |
| `/cto-security:secure-by-design-program` | Establish org-wide secure-by-design: paved roads, guardrails, developer enablement. |
| `/cto-security:tech-risk-assessment` | Assess technology/product risk for a strategic decision (new tech, build/buy, vendor, M&A). |

## Agents

| Agent | Use for |
| --- | --- |
| `cto-security-advisor` | Technology-strategy security: secure-by-design at scale and tech-risk decisions. |

## CISO vs CTO

- **`ciso-toolkit`** — owns security risk, strategy, and board communication.
- **`cto-security`** *(this)* — builds security into the technology and engineering
  org so the secure path is the default, fast path.

Complementary executive roles; install both for full coverage of the leadership layer.
