# mobile-security

Mobile application security for Android and iOS. Review against the **OWASP MASVS**
and run a **MASTG**-based testing methodology covering storage, crypto, auth,
network, platform interaction, code quality, and resilience.

A **domain** plugin; member of the planned `appsec-suite`. Authorized testing only.

## Install

```
/plugin install mobile-security@awesome-claude-security
```

## Skills

| Skill | When it fires |
| --- | --- |
| `/mobile-security:masvs-review` | Review a mobile app against OWASP MASVS control groups. |
| `/mobile-security:mobile-pentest` | Run a MASTG-based static + dynamic mobile pentest. |

## Pairs well with

`api-security` (mobile backends), `pentester`, `sast-sca`, `security-reporting`.
