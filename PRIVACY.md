# Privacy Policy

_Last updated: 2026-06-28_

This privacy policy covers the **awesome-claude-security** Claude Code plugin
marketplace and all plugins distributed from it (including
`claude-config-security`).

## Summary

**These plugins collect no data, contain no telemetry, and run entirely on your
own machine.** There is no backend service operated by this project, no account,
and no tracking.

## What the plugins do with your data

- The plugins are **skills, agents, and reference material** that run locally
  inside your own Claude Code session. They process only the files and inputs you
  point them at, on your own device.
- They do **not** transmit your code, configuration, prompts, scan results, or any
  other content to any server operated by this project or its maintainers.
- No analytics, telemetry, cookies, identifiers, or usage metrics are collected.
- Nothing is stored by this project. Any output (reports, findings, diagrams) is
  written only to your local filesystem, where you control it.

## Third-party tools

Some plugins invoke independent, open-source command-line tools that you install
and run yourself — for example, `claude-config-security` drives the
[`agentscanner`](https://pypi.org/project/agentscanner/) CLI (Apache-2.0).

- These tools also run **locally** and are configured to read your files as data
  only.
- They are not operated by this project. Their own behavior and any privacy terms
  are governed by their respective publishers.
- Installing or running them is at your discretion; this project does not vendor,
  bundle, or proxy them.

## Claude Code and your model provider

These plugins operate within Claude Code. Your interactions with the underlying
AI model are handled by **Claude Code and your chosen model provider (e.g.
Anthropic)** under **their** terms and privacy policies — not by this project.
This project has no visibility into, and no control over, that data flow.

## Changes

This policy may be updated as the project evolves. Material changes will be
reflected in this file's history in the public repository.
